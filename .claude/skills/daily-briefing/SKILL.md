# 스킬 1: 데일리 채용 브리핑 🔍

매일 아침 실행되는 "채용 스캐너". 트리거: `브리핑`, `오늘 채용`, 또는 공고 목록 붙여넣기.

## 준비: 항상 먼저 읽을 파일
1. `job-hunt/profile.md` — 매칭 기준 (기술스택/선호/기피)
2. `job-hunt/tracker.md` — 현재 지원 현황
3. (있으면) `job-hunt/experience-blocks.md` — 매칭 근거 보강용

## 절차

### Step 1 — 마감 임박 분류 (tracker.md 기반)
오늘 날짜 기준으로 지원 완료(📨/✅/❌)가 아닌 건들을 마감일로 분류:
- 🚨 **긴급** — 오늘/내일 마감
- ⚡ **주의** — 이번 주 마감
- 📅 **일반** — 다음 주 이후 마감
각 건에 대해 자소서 파일 유무를 함께 표기 ("자소서 있음 → 제출만" / "미작성 → 오늘 시작 권장").

### Step 2 — 신규 공고 수집
아래 중 가능한 방법으로 새 공고를 확보:
- **(기본) 붙여넣기**: 사용자가 붙여넣은 공고 텍스트를 파싱. 가장 안정적.
- **(선택) 웹 탐색**: 사용자가 채용 사이트 URL을 지정했으면 WebFetch로 조회. 로그인/봇 차단 시 실패를 알리고 붙여넣기로 유도.
각 공고에서 추출: `회사 / 직무 / 마감일 / 필수요건 / 우대사항 / 원문링크`.

### Step 3 — 매칭 스코어 산출
`profile.md`의 "매칭 스코어 산출 기준" 가중치로 각 공고를 0~100% 채점:
- ⭐ **적극 지원** (80%+) — 매칭 근거를 경험 블록과 연결해 한 줄로 제시
- 🔵 **조건부 추천** (60~79%) — 부족한 요건을 함께 명시
- ❌ **비매칭** (60% 미만) — **제외 사유를 반드시 표기** (예: "경력 5년 요구 — 불일치")
기피 조건(profile.md)에 걸리면 점수와 무관하게 ❌ 처리.

### Step 4 — 트래커 반영 제안
매칭된 신규 공고(⭐/🔵)를 `tracker.md`에 `🔍 발굴` 상태로 추가할지 물어보고, 승인 시 표에 행 추가.

### Step 5 — (선택) 캘린더 동기화
Google 캘린더 MCP가 연결되어 있으면:
- 트래커에 있으나 캘린더에 없는 마감 → "등록할까요?" 제안
- 캘린더에 있으나 트래커에 없는 건 → "미등록 경고"
- 등록 시 긴급도별 색상 구분 (🚨 빨강 / ⚡ 주황 / 📅 기본)
MCP 미연결 시 이 단계는 건너뛰고 "캘린더 미연동 — 트래커로만 관리 중"이라고 한 줄 안내.

## 출력 형식
```
📋 오늘의 채용 브리핑 (YYYY-MM-DD)

🚨 긴급: {회사} {직무} ({마감})
   → {자소서 상태}

⚡ 이번 주: {회사} {직무} ({마감})
   → {자소서 상태}

🔍 신규 매칭 공고 N건:
⭐ {회사} {직무} ({마감}) — 매칭 {점수}%  · {근거 한 줄}
🔵 {회사} {직무} ({마감}) — 매칭 {점수}%  · {부족 요건}
❌ {회사} {직무} — 제외: {사유}

→ {제안: 트래커 추가 / 캘린더 등록 등}
```
