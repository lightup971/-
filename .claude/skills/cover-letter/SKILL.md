# 스킬 2: 자소서 자동 생성 ✍️

트리거: `{회사} 자소서 써줘`, `{공고} 자소서 초안` 등. 단순 작문이 아니라 **6단계 파이프라인**을 순서대로 실행하고, 각 단계 결과를 짧게 보고하며 진행한다.

## 준비: 항상 먼저 읽을 파일
- `job-hunt/experience-blocks.md` — 경험 블록 (A~V)
- `job-hunt/profile.md` — 프로필
- `job-hunt/strategies/*.md` — KKK / STAR-F / 3C4P 전략
- 대상 JD (사용자 붙여넣기 또는 tracker의 원문링크)

경험 블록이 비어 있으면(예시만 있으면) 먼저 사용자에게 채워달라고 안내한다. 없으면 초안 품질이 나오지 않는다.

## 파이프라인

### Step 0 — 회사 조사
지원 회사의 최근 뉴스/투자/전략/서비스를 WebSearch로 조사. 웹 불가 시 사용자에게 아는 정보를 물어 대체. 조사 결과는 KKK 전략의 K1/K2 근거로 사용.

### Step 1 — 역량 추출 & 블록 매칭
JD에서 요구 역량을 추출(필수/우대 구분)하고, 각 역량을 경험 블록과 매칭.
- 커버리지 산출: 요구 역량 중 블록으로 뒷받침되는 비율(%)
- 매칭표 출력: `요구역량 → 블록 X (태그)`
- 커버리지가 낮으면 어느 역량이 비었는지 알리고, 우회 서술 or 사용자 추가 경험을 요청.

### Step 2 — 문항 유형 분석 & 전략 선택
각 자소서 문항의 유형을 판별해 전략 배정:
- 지원동기 / 입사 후 포부 → **KKK**
- 직무역량 / 성취 경험 → **STAR-F**
- 협업 / 갈등 → **3C4P**
- 기타 → 가장 가까운 전략을 선택하고 이유를 한 줄 명시.

### Step 3 — 초안 작성
문항별로 배정된 전략 구조에 맞춰, 매칭된 블록을 근거로 초안 작성.
- 글자 수 제한이 명시됐으면 ±5% 이내로 맞춘다.
- 회사 고유 사실(Step 0)을 최소 1회 반영.
- 주어는 "나"로, 결과는 숫자로.

### Step 4 — 자체 검증 (체크리스트)
초안을 아래로 스스로 점검하고, 걸리는 항목은 수정 후 통과시킨다.
- [ ] 각 문항이 배정 전략 구조를 지키는가
- [ ] 정량 결과(숫자)가 있는가
- [ ] 회사 고유 사실이 들어갔는가
- [ ] 글자 수 제한 충족
- [ ] **AI 유사성 7패턴 체크** (아래) — 걸리면 다시 씀
  1. 과도한 "~을 통해", "~함으로써" 반복
  2. "귀사의 발전에 기여" 류 공허한 상투구
  3. 모든 문단이 같은 길이/리듬
  4. 근거 없는 형용사 남발("탁월한", "혁신적인")
  5. 구체적 숫자·고유명사 부재
  6. 접속사로만 이어지는 나열식 전개
  7. 지원자 고유 목소리(1인칭 관점/감정) 부재

### Step 5 — 최종본 출력 & 저장
- 최종본을 `job-hunt/cover-letters/{회사}-{직무}.md`로 저장. 파일 상단에 상태 프론트매터:
  ```
  ---
  company: {회사}
  role: {직무}
  status: draft   # draft → done (제출 시 스킬 3이 변경)
  created: YYYY-MM-DD
  ---
  ```
- 사용자에게 "초안 생성 완료 — 검토해주세요"와 함께, 손봐야 할 20%(고유 목소리 필요 지점)를 짚어준다.
- tracker.md의 해당 행 상태를 `✍️ 작성중`으로, 자소서 파일 경로를 채운다.

## 원칙
초안은 80점. "나만의 목소리"는 사용자가 다듬는다고 명확히 안내. 100% 자동 완성이라고 과장하지 않는다.
