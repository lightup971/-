# 스킬 3: 제출 완료 처리 ✅

트리거: `{회사} 제출했어`, `{회사} 지원 완료` 등. 한 마디로 아래 3곳을 동시 업데이트한다.

## 절차

### 1. 대상 특정
사용자가 말한 회사/직무로 tracker.md에서 해당 행을 찾는다. 후보가 여럿이면 어느 건인지 되묻는다.

### 2. 자소서 파일 상태 변경
`job-hunt/cover-letters/{회사}-{직무}.md`의 프론트매터 `status: draft` → `status: done`.
파일이 없으면 그 사실을 알리되 나머지 업데이트는 계속 진행.

### 3. 트래커 업데이트
tracker.md 해당 행:
- 상태 → `📨 지원 완료`
- 제출일 → 오늘 날짜 (YYYY-MM-DD)

### 4. (선택) 캘린더 이벤트 변경
Google 캘린더 MCP 연결 시 해당 마감 이벤트:
- 제목 앞에 `✅ [제출완료]` 추가
- 색상 → 초록색
MCP 미연결 시 이 단계 건너뛰고 한 줄 안내.

## 출력 형식
```
✅ {회사} {직무} 제출완료 처리 완료
   - 자소서: {파일} → done
   - 트래커: 📨 지원 완료 (YYYY-MM-DD)
   - 캘린더: ✅ [제출완료] {회사} {직무} (색상 변경)   ← 연동 시에만
```

## 원칙
3곳 중 일부만 가능해도(예: 캘린더 미연동) 가능한 것만 처리하고, 무엇을 했고 무엇을 못 했는지 정확히 보고한다.
