# 채용 지원 자동화 시스템

채용공고 검색 → 데이터 정리 → JD 분석 및 자소서 작성까지를 자동화하는 개인 취업 비서.
[클로드 코드 팁 #4] 아티클의 "스킬 3개" 구조를 그대로 구현했습니다.

## 구조

```
job-hunt/
├── profile.md            ← 내 프로필 (매칭 기준: 기술스택/선호/기피)   ★먼저 채우기
├── experience-blocks.md  ← 경험 블록 A~V (자소서 재료)                ★먼저 채우기
├── tracker.md            ← 지원 트래커 (모든 현황 한 곳에)
├── strategies/           ← 자소서 글쓰기 전략
│   ├── KKK.md            (지원동기)
│   ├── STAR-F.md         (직무역량)
│   └── 3C4P.md           (협업/갈등)
└── cover-letters/        ← 생성된 자소서 저장 위치

.claude/skills/
├── daily-briefing/       스킬 1 — "브리핑"
├── cover-letter/         스킬 2 — "OO 자소서 써줘"
└── submit-done/          스킬 3 — "OO 제출했어"
```

## 매일의 흐름

| 시점 | 말 한마디 | 스킬이 하는 일 |
|---|---|---|
| 아침 | `브리핑` | 마감 임박 분류 + 신규 공고 매칭 스코어 + 트래커/캘린더 정리 |
| 작성 | `카카오 PM 자소서 써줘` | 6단계 파이프라인으로 80% 초안 생성 |
| 제출 후 | `네이버 제출했어` | 자소서 상태 + 트래커 + 캘린더 동시 업데이트 |

공고 목록을 커뮤니티/오픈채팅에서 복붙해서 `브리핑`에 붙여넣어도 전부 분석됩니다.

## 시작하기 (최초 1회)

1. **`profile.md` 채우기** — 기술 스택, 선호/기피 조건. 매칭 정확도의 기준.
2. **`experience-blocks.md` 채우기 (제일 중요)** — 경험을 10~20개 블록으로.
   한 번 만들면 모든 자소서에 재활용됩니다. 결과는 **숫자로** 적으세요.
3. 이후부터는 `브리핑` 한마디로 시작.

## 캘린더 연동 (선택)

Google 캘린더 MCP를 붙이면 마감일 자동 등록/색상 구분/제출 처리까지 이어집니다.
미연동 상태에서도 **공고 매칭 + 자소서 자동 생성 + 트래커 관리**만으로 충분히 동작합니다.

## 한계 (솔직하게)
- 경험 블록 초기 작성에 시간이 듭니다. (단, 재활용 효율은 큼)
- 자소서 초안은 80점 — "나만의 목소리"는 직접 다듬어야 합니다.
- 코딩테스트는 자동화 대상이 아닙니다.
