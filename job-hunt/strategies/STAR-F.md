# STAR-F 전략 — 직무역량 문항용

> **적용 문항 유형**: "직무 관련 경험", "가장 큰 성취", "역량을 발휘한 사례"
> **핵심 순서**: Situation → Task → Action → Result → Feeling(느낀점)

## 구조
1. **S — 상황(Situation)**: 문제/배경을 1~2문장으로 압축. 장황하면 감점.
2. **T — 과제(Task)**: 내가 맡은 목표/역할을 분명히.
3. **A — 행동(Action)**: **내가** 한 구체적 행동. 주어는 항상 "나". (팀이 아니라)
   - 여기가 분량의 절반 이상. 무엇을·왜·어떻게 결정했는지.
4. **R — 결과(Result)**: **숫자로.** (전/후 비교, %, 시간, 금액)
5. **F — 느낀점(Feeling)**: 배운 것 → 지원 직무에서 어떻게 재현할지로 연결.

## 체크
- [ ] Action에서 주어가 "우리"가 아니라 "나"인가?
- [ ] Result에 정량 지표가 있는가?
- [ ] 느낀점이 자기반성에서 끝나지 않고 지원 직무로 연결되는가?
