슬랙 API 연동 없이 자동화하는 방법
① 복사 → 붙여넣기 + 슬랙 예약 발송 승인 불필요
직접 입력 탭에서 문구 생성 → 복사 → 슬랙 DM 창에 붙여넣고, 전송 버튼 옆 예약 발송으로 시간을 지정합니다. 별도 권한이 필요 없어 가장 안전합니다.
② Claude + 슬랙 커넥터 코딩 불필요
claude.ai 또는 Claude 데스크톱에서 Slack을 커넥터로 연결(관리자 OAuth 승인)한 뒤, “이 명단에 이 문구를 DM 보내줘”라고 지시하면 Claude가 발송합니다. 직접 API 서버를 만들 필요가 없습니다.
③ Claude MCP + 슬랙 MCP 서버
Claude 데스크톱/코드에 오픈소스 Slack MCP 서버를 등록하고 개인 슬랙 토큰 하나만 발급하면, Claude가 DM 발송을 대신합니다. 서버를 직접 개발/운영할 필요가 없습니다.
④ 노코드 자동화(Zapier/Make) + Claude
Claude로 문구를 생성하고 Zapier의 Slack “Send Direct Message” 액션으로 발송합니다. Zapier가 슬랙 인증을 대신 처리합니다.
어떤 방식이든 실제 DM 전송은 결국 슬랙의 OAuth 인증을 거칩니다. 다만 ①~④는 사내 IT가 별도 API 서버를 구축할 필요가 없는 방법들입니다.
슬랙 Bot Token 발급 방법
1
앱 생성
api.slack.com/apps → Create New App → From scratch → 앱 이름 입력 → 워크스페이스 선택
2
권한 설정
OAuth & Permissions → Bot Token Scopes 에서 chat:write, users:read.email 추가
3
설치 및 토큰 복사
Install to Workspace → Bot User OAuth Token (xoxb-...) 복사 후 슬랙 탭에 붙여넣기
엑셀 파일 예시 형식
이름생년월일부서슬랙 ID
홍길동1992-05-14개발팀U01ABCDEF
김철수1990-05-28마케팅팀hong@burrng.com

슬랙 ID는 멤버 프로필 → 케밥 메뉴 → 슬랙 ID 복사에서 확인. 이메일로도 자동 조회됩니다.

슬랙 API는 브라우저 CORS 정책으로 인해 직접 호출이 차단될 수 있습니다. 그 경우 슬랙 발송용 Excel을 다운받아 슬랙 앱에서 직접 메시지를 복사·붙여넣기 하거나, 사내 서버/프록시를 통해 API를 호출하는 방식을 사용하세요.
