수정신고 업로드파일 생성기

구글시트에서 오늘 처리할 건만 붙여넣으면 ERP·홈택스 업로드 파일을 한 번에 만들어 줍니다

1데이터 붙여넣기

구글시트 수정신고_부릉에서 오늘 처리할 행들의 H열(일자)부터 AC열(최종 지방소득세)까지 드래그로 선택 → 복사(Ctrl+C) → 아래 칸에 붙여넣기(Ctrl+V)하세요. 소득자 그룹의 첫 행(소득자명이 있는 행)부터 포함해서 선택해야 합니다.

붙여넣는 열 순서 확인 (H → AC)
H 일자I 소득자명J 주민번호 K 기사코드L 지급연월M 소득금액 N 세율O 실지급액P 소득세 Q 지방소득세R 부인신청내역S~U 부인 기존 V 변경 소득자명W 주민번호X~Z 해당자 기존 AA 최종 소득금액AB 최종 소득세AC 최종 지방소득세

2결과 확인 & 다운로드

ERP + 홈택스 파일을 한 번에
구분 소득자명
(파일 미포함)		 소득자코드지급연월귀속년월지급일 사업장부서지급액업종세율소득세지방세상태

수정신고는 귀속월별로 따로 업로드해야 하므로, 붙여넣은 기간을 월별 파일로 자동 분리했습니다. 각 파일을 홈택스 [엑셀서식작성] → [찾아보기] 업로드 → [검증하기] 하세요.

홈택스 파일 내용 미리보기
귀속No구분소득자성명주민(사업자)등록번호 내외국인업종지급액세율소득세지방소득세
ERP · 양식 TSMINC00700_F과 컬럼·시트명이 같고 모든 셀이 텍스트 서식 → 옴니이솔 [엑셀파일업로드] → 오류검증 → 서식반영.
홈택스 · 국세청 간이지급명세서 양식(Sheet1)과 컬럼·타입·서식이 동일하며 귀속월별로 파일이 분리됩니다. 같은 소득자가 한 달에 두 번 나오면 합산해 한 줄로 만듭니다. 내외국인('1'/'9')은 주민번호 뒷자리로 자동 판별합니다.
구분 · 부인 = 소득부인자 정정 행(시트 S·T·U열, 전액부인이면 0), 해당 = 소득해당자 반영 행(AA·AB·AC열).
참고 · 최종 소득세는 (기존 + 부인) 합산이라 지급액×3%와 몇 원 다를 수 있으며 정상입니다.
