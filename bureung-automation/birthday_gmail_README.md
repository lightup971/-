# 생일휴가 안내 – 사원명부 → Gmail 자동 발송

ERP에서 내려받은 **사원명부 엑셀을 그대로 붙여넣기만** 하면, 해당 월 생일자에게
생일휴가 안내 메일을 자동 발송합니다. **생년월일에서 생일월을 자동 계산**하므로
이메일·생일월을 따로 입력할 필요가 없습니다.

- 슬랙 봇 토큰·외부 API·서버 **불필요**
- **관리자 승인 불필요** — 최초 1회 본인 구글 계정 권한 승인만
- 임원/장애인고용 부서 **자동 제외**, 재직자만 발송, **중복발송 자동 방지**

## 1. 사원명부 붙여넣기
1. 새 구글 스프레드시트 생성
2. ERP 사원명부 export(예: `사원명부...260622`)를 **1행 머리글째 그대로** 붙여넣기
   - 인식 컬럼: `성명 · 생년월일 · 이메일 · 재직여부 · 사원번호 · 직급/직책/직위 · 부서`
   - 컬럼 순서·개수는 상관없음(머리글 이름으로 자동 인식)

## 2. 스크립트 설치
1. **확장 프로그램 → Apps Script**
2. `birthday_gmail_sender.gs` 전체 붙여넣고 저장(💾)
3. 스프레드시트 새로고침 → 상단 **🎂 생일휴가 안내** 메뉴 생성

## 3. 사용 (매월 이 순서)
1. **① 이번 달 대상자 미리보기** — 발송/제외/이메일없음 명단과 예시 메일 확인
2. **② 나에게 테스트 발송** — 내 메일로 견본 1통
3. **③ 이번 달 생일자에게 발송** — 대상 월 입력(기본 이번 달) → 인원 확인 → 발송
   - 최초 실행 시 구글 권한 승인 팝업: 본인 계정 → 고급 → 허용
   - `_발송기록` 시트에 사원번호+연월으로 남겨 **같은 달 중복발송을 자동 차단**
     (사원명부를 새로 붙여넣어도 유지됨)

## 4. 매월 운영 방법
- 이메일은 잘 안 바뀌므로, 최신 사원명부를 **한 번 붙여두면** 매달 그 월만 자동 필터됩니다.
- 신규 입사자가 생기면 **최신 사원명부를 다시 붙여넣기**만 하면 반영됩니다(개인별 조회 불필요).
- 260622 기준 파일에서 이메일 없는 2명(장원경·전승용)은 **장애인고용 부서 = 생일휴가 제외 대상**이라 발송 목록에 애초에 포함되지 않습니다.

## 5. 문구·규칙 수정
스크립트 상단 `CONFIG`와 `BODY_TEXT`에서:
- `SUBJECT` / `BODY_TEXT` — 제목·본문(`{이름}`,`{월}`,`{말일}` 자동 치환, 텍스트+HTML 동시 발송)
- `INCLUDE_STATUSES` — 기본 `['재직']`. 휴직자도 보내려면 `['재직','휴직']`
- `USE_GIVEN_NAME_ONLY` — `true`면 인사말에 성을 뗀 이름(김민희 → 민희님)
- `EXCLUDE_RANKS` / `EXCLUDE_DEPTS` — 임원/제외 부서 규칙
- `RESEND` — `true`면 같은 달 재발송 허용

## 참고 – 발송 한도
개인 Gmail 하루 약 500통 / Workspace 약 1,500통(다음 날 초기화). 생일자 규모(월 10~25명)에는 넉넉하며, 스크립트가 발송 전 잔여 한도를 확인합니다.
