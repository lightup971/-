# 생일휴가 안내 – 구글 스프레드시트 → Gmail 자동 발송

슬랙 봇 토큰이나 별도 API 없이, **구글 스프레드시트 + 내장 Apps Script(Gmail)** 만으로
생일자에게 안내 메일을 발송하는 도구입니다. 최초 1회 **본인 구글 계정 권한 승인**만 필요하고,
관리자 승인이나 외부 서버는 필요 없습니다.

## 1. 명단 시트 준비
새 구글 스프레드시트를 만들고 1행에 머리글을 넣습니다. 순서·이름은 유연하게 인식됩니다.

| 이름 | 이메일 | 생일월 |
|------|--------------------------|--------|
| 김민희 | minhee.kim@vroong.com | 7 |
| 홍길동 | gildong.hong@vroong.com | 7 |

- **이메일**: 필수. (`이메일`, `메일`, `email`, `gmail` 중 아무 머리글이나 인식)
- **생일월**: 1~12 숫자. 이 컬럼이 있으면 해당 월만 발송, 없으면 명단 전체 발송.
- `발송상태`, `발송일시` 컬럼은 **없어도 됩니다** — 스크립트가 자동으로 만들어 기록하고
  중복 발송을 막습니다.

## 2. 스크립트 설치
1. 스프레드시트에서 **확장 프로그램 → Apps Script**
2. `birthday_gmail_sender.gs` 내용을 전체 붙여넣고 **저장**(💾)
3. 스프레드시트로 돌아가 **새로고침** → 상단에 **🎂 생일휴가 안내** 메뉴 생성

## 3. 사용
메뉴에서 순서대로:
1. **① 미리보기 (첫 대상자)** — 실제 나갈 제목/본문 확인
2. **② 나에게 테스트 발송** — 내 메일로 견본 1통 발송 (안전 확인)
3. **③ 이번 달 생일자에게 발송** — 대상 월 입력(기본 이번 달) → 인원 확인 → 발송
   - 최초 실행 시 구글 권한 승인 팝업이 뜹니다: 본인 계정 선택 → 고급 → 허용
   - 이미 `발송완료`된 행은 자동 제외(재발송하려면 코드의 `RESEND_ALREADY_SENT`를 `true`로)

기타: **발송 상태 초기화**, **남은 일일 발송량 확인** 메뉴 제공.

## 4. 문구 수정
스크립트 상단의 `BODY_TEXT`(본문)와 `CONFIG.SUBJECT`(제목)를 고치면 됩니다.
`{이름}`, `{월}`, `{말일}`은 발송 시 자동으로 채워집니다. (텍스트/HTML 메일 동시 발송)

## 5. (선택) 매월 자동 발송
Apps Script 편집기 → 왼쪽 **트리거(⏰)** → **트리거 추가**
- 실행할 함수: `sendBirthdayEmails` … 는 확인 팝업이 있어 자동실행에 부적합합니다.
- 완전 자동화가 필요하면 확인창 없이 도는 `sendBirthdayEmailsAuto` 같은 함수를 별도로 두고
  월 1회 트리거를 거는 방식을 권장합니다(필요하시면 추가해 드립니다).

## 참고 – 발송 한도
- 개인 Gmail: 하루 약 500통 / Google Workspace: 하루 약 1,500통 (다음 날 초기화)
- 생일자 규모에서는 넉넉합니다. 스크립트가 발송 전 남은 한도를 확인합니다.
