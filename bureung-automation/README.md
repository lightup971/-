# 부릉 사업소득 수정신고 — 자동화 도구

`수정신고_부릉` 시트의 데이터를 **ERP(옴니이솔) 업로드 엑셀**로 자동 변환해서,
구글시트 ↔ ERP 창 전환과 수기 입력을 줄여줍니다.

> 목표: 매뉴얼 「01. ERP 사업소득 데이터 수정 → 방법2 엑셀업로드」 단계를 버튼 한 번으로.
> (홈택스 간이지급명세서 생성기는 국세청 업로드 양식 확보 후 추가 예정)

## 두 가지 사용 방식 (택1)

| | **A. 웹 도구 (권장)** `erp-generator.html` | **B. 시트 메뉴** `ERP_업로드_생성기.gs` |
|---|---|---|
| 방식 | 오늘 처리할 행만 **복사→붙여넣기** | 시트에서 행 선택 후 **메뉴 클릭** |
| 설치 | 필요 없음 (브라우저에서 바로) | Apps Script 1회 설치 |
| 적합 | 수천 건 중 N건만 뽑을 때 | 시트에 상시 붙여두고 쓸 때 |
| 결과 | 미리보기 확인 후 .xlsx 다운로드 | 새 시트 생성 후 .xlsx 다운로드 |

두 방식 모두 **같은 변환 로직**(코어 `erp_core.js`)을 쓰고, 결과 xlsx는 동일합니다.

### A. 웹 도구 사용법 (`erp-generator.html`)
1. 브라우저에서 파일을 연다 (또는 게시된 Artifact 링크)
2. 구글시트 `수정신고_부릉`에서 오늘 처리할 행의 **H열~AC열**을 선택 → 복사
   *(소득자 그룹의 첫 행 = 소득자명 있는 행부터 포함)*
3. 붙여넣기 → **[변환하기]** → 미리보기로 금액·코드 확인
4. **[⬇ 전체 받기(.zip)]** 한 번이면 끝 — ERP 파일 + 홈택스 월별 파일이 모두 들어 있습니다.
   ```
   수정신고_업로드파일_YYYYMMDD_HHMM.zip
   ├─ ERP/     ERP업로드_….xlsx                 → 옴니이솔 [엑셀파일업로드]
   └─ 홈택스/   간이지급명세서_202503.xlsx        → 홈택스 [엑셀서식작성] (월별로 각각)
               간이지급명세서_202504.xlsx
               …
   ```
5. 따로 받고 싶으면 아래 **탭 두 개**에서 개별 다운로드도 가능합니다.
   - **[ERP 업로드]** 탭 → ERP `.xlsx`만
   - **[홈택스 간이지급명세서]** 탭 → 월별 개별 또는 홈택스만 묶은 `.zip`
   - 처음이면 **[예시 채우기]** 로 동작을 먼저 확인해볼 수 있음

## 1. 설치 (최초 1회, 5분)

1. `수정신고_부릉` 이 들어 있는 구글 스프레드시트를 연다
2. 상단 **[확장 프로그램] → [Apps Script]**
3. 기존 코드 지우고 **`ERP_업로드_생성기.gs`** 내용을 통째로 붙여넣기 → 저장(💾)
4. 스프레드시트로 돌아가 **새로고침(F5)** → 상단 메뉴에 **[부릉 자동화]** 가 생김
5. 처음 실행 시 구글 권한 승인 창이 뜨면 본인 계정으로 허용

## 2. 사용법

### ① ERP 업로드파일 생성 (소득해당자)

1. (권장) 이번에 처리할 **행들을 드래그로 선택** — 선택한 행만 생성됨
   *아무것도 선택 안 하면 시트 전체가 대상이 되어 과거 완료분까지 다시 나옵니다.*
2. **[부릉 자동화] → [① ERP 업로드파일 생성(소득해당자)]**
3. 새 스프레드시트가 만들어지고 링크가 뜸 → 그 파일을 열어
   **[파일] → [다운로드] → [Microsoft Excel(.xlsx)]**
4. 옴니이솔 **[사업기타이자배당소득엑셀업로드] → [엑셀파일업로드]**
   → 전체 선택 → **[오류검증]** → '정상' 확인 → **[서식반영]**

각 월(月)마다 **부인자 행(S·T·U, 전액부인이면 0) + 해당자 행(AA·AB·AC)** 두 줄이 함께 생성됩니다.
생성물은 실제 ERP 양식(`TSMINC00700_F`)과 컬럼·시트명이 동일하며,
**모든 셀이 텍스트 서식**으로 채워집니다(매뉴얼의 "숫자(X) 텍스트(O)" 준수).

- 포함 대상은 `CONFIG.INCLUDE`(웹 도구는 '포함 대상' 선택)로 조절: `BOTH`(기본) / `HAING`(해당자만) / `BUIN`(부인자만).

### ② 부인자 목록 (참고용)

부인자 정정은 이제 ①에서 0·0·0 행으로 함께 업로드됩니다. 이 메뉴는 **[부인자명 / 소득자코드 / 주민번호 / 귀속연월 / 금액]**
목록을 따로 확인하고 싶을 때 쓰는 참고용입니다. (엑셀업로드 대신 수동으로 승인해제+삭제할 경우에도 활용)

## 3. 컬럼 매핑 (기본값)

| ERP 양식 | 값 출처 |
|---|---|
| `INCMPER_NO` 소득자코드 | (아래 4번 참고 — 소득자코드 매핑) |
| `PAY_YM` 지급연월 | `지급연월`(L) → `YYYYMM` |
| `RVERS_YM` 귀속년월 | `지급연월`(L) → `YYYYMM` (귀속=지급 동일 처리) |
| `PAY_DT` 지급일 | 해당월 **말일** `YYYYMMDD` |
| `BIZAREA_CD` 사업장코드 | `1000` (고정) |
| `DEPT_CD` 부서코드 | `AE0000000` (고정) |
| `WGS_AMT` 지급액 | **부인자 = `S`열** (전액부인 0·부분부인 잔여) / 해당자 = `AA`열, 비면 `해당자기존(X)+부인(M)` |
| `BIZTP_FG_CD` 업종구분코드 | `940918` 퀵서비스 (고정) |
| `TAX_RT` 세율 | `3` (고정) |
| `INTAX_AMT` 소득세금액 | **부인자 = `T`열** / 해당자 = `AB`열 *(폴백 시 Y+P)* |
| `LOCINTAX_AMT` 지방소득세금액 | **부인자 = `U`열** / 해당자 = `AC`열 *(폴백 시 Z+Q)* |

> **부인자(S·T·U) / 해당자(AA·AB·AC)** — 소득부인자 정정금액은 시트 S·T·U열(전액부인이면 0),
> 소득해당자 반영금액은 AA·AB·AC열을 그대로 최종금액으로 사용합니다.

- **소득세 정합성 참고:** 최종 소득세 = 기존 + 부인(각각 따로 반올림된 값의 합)이라
  `지급액 × 3%` 와 몇 원 다를 수 있습니다. 이는 정상이며, 기존 신고분을 보존하는 올바른 값입니다.

## 4. 소득자코드(INCMPER_NO) — 이름 셀에서 자동 추출

ERP 업로드 양식에는 **이름·주민번호 칸이 없고** `INCMPER_NO`(소득자코드)로만 소득자를 식별합니다.

이미 하시던 방식 그대로 됩니다: **해당자 이름 셀에 `이름` 적고 Alt+Enter로 줄 띄운 뒤
ERP에서 찾은 소득자코드를 적어두면**, 생성기가 그 **맨 끝 숫자를 소득자코드로 자동 추출**합니다.
줄바꿈이든 공백이든(`김승수\n36510`, `김혜영 861`) 모두 인식합니다.

- **자릿수 자동 보정:** 코드를 6자리로 0을 채웁니다 (예: `2077 → 002077`, `861 → 000861`).
  ERP 실제 코드 형식이 다르면 `CONFIG.CODE_PAD_LEN` 값을 바꾸거나 `0`으로 끄세요.
- **코드 없는 대상**은 생성 후 경고창에 명단으로 뜨고, 그 셀은 비어서 나옵니다.
  이름 셀에 코드를 적어두거나, 신규 소득자면 매뉴얼 FAQ(신규 등록)로 먼저 코드를 부여하세요.

> (선택) 이름 셀 대신 별도 관리하고 싶으면 `소득자코드매핑` 시트(A=주민번호, B=소득자코드)를
> 만들어두면 이름 셀에 코드가 없을 때 보조로 사용합니다. 또는 `수정신고_부릉`에 코드 전용 열을
> 만들고 `CONFIG.COL.해당자_소득자코드`에 열번호를 지정할 수도 있습니다.

> **참고 — 주민/외국인등록번호 대신 소득자코드를 쓰는 이유:** ERP 양식은 소득자코드 칸을
> 주민등록번호·외국인등록번호 두 칸으로 대체할 수도 있지만, 그 경우 내/외국인 여부를 먼저
> 가려 각각 다른 칸에 넣어야 해 번거롭습니다. 소득자코드 한 칸이면 내·외국인 구분 없이 일괄
> 처리돼서, 이 생성기도 소득자코드 방식으로 만들었습니다.

## 5. 값이 실제와 다르면?

`.gs` 파일 맨 위 **`CONFIG`** 블록만 고치면 됩니다. 예:

- 지급액 기준을 '이관금액만 추가'로 바꾸려면 → `AMOUNT_BASIS: 'DENIED'`
- 부서코드/세율/업종코드 변경 → 해당 값 수정
- 시트 열 순서가 바뀌면 → `CONFIG.COL` 의 열번호만 수정

## 5-2. 홈택스 간이지급명세서 생성 (`hometax_core.js`)

국세청 간이지급명세서(거주자의 사업소득) 업로드 양식으로 변환합니다.
**수정신고는 귀속월마다 따로 올려야 하므로, 붙여넣은 기간을 월별 파일로 자동 분리**합니다.
(1~4월을 한 번에 붙여넣으면 → 파일 4개)

| 홈택스 양식 (Sheet1) | 타입 | 값 출처 |
|---|---|---|
| A `일련번호` | 숫자 | 1부터 순차 (파일마다 다시 1) |
| B `귀속연도` | 숫자 | 지급연월(L)의 연도 |
| C `귀속월` | 문자 | 지급연월(L)의 월 `'01'` 형식 |
| D `업종코드` | 숫자 | `940918` 퀵서비스 |
| E `소득자성명(상호)` | 문자 | 이름만 (소득자코드는 자동 제거) |
| F `주민(사업자)등록번호` | 문자 | 13자리, **하이픈 없음** |
| G `내외국인` | 문자 | 주민번호 뒷자리로 자동 판별 (1~4 → `'1'`, 5~8 → `'9'`) |
| H `지급액` | 숫자 | 부인자 = S열 / 해당자 = AA열 (음수 불가, 없으면 0) |
| I `세율` | 문자 | `'3'` |
| J `소득세` | 숫자 | 부인자 = T열 / 해당자 = AB열 |
| K `지방소득세` | 숫자 | 부인자 = U열 / 해당자 = AC열 |

- ⚠️ **컬럼마다 타입이 다릅니다**(숫자/문자 혼합). ERP 양식처럼 전부 텍스트로 만들면 안 되며,
  생성기는 원본 양식과 **타입·표시형식·시트 구성(3시트)까지 동일**하게 만듭니다.
- **중복 합산**: 같은 주민번호가 같은 귀속월에 두 번 나오면 지급액·소득세·지방소득세를 **합산해 한 줄**로 만듭니다
  (홈택스는 소득자별 1행 기준).
- **주민번호 누락 시 경고**: 홈택스 필수값이라 비어 있으면 검증 오류가 납니다 → 화면에 명단으로 표시됩니다.
- 파일명 `간이지급명세서_YYYYMM.xlsx` (홈택스 파일명 30자 제한 준수), 1,000행 초과 시 경고.

## 6. 아직 수동인 부분 / 다음 단계

- **부인자 정정**: ①에서 S·T·U열 값(전액부인 0, 부분부인 잔여액) 행으로 함께 업로드됩니다(수동 삭제 불필요).
- **홈택스 간이지급명세서**: 완료 — 월별 파일 자동 분리까지 지원.
- **홈택스 지급명세서(연별)**: 아직 미지원. 연간 합산 + (A)/(B)/(C) 검증 흐름이라 별도 설계 필요.
- 홈택스는 공동인증서 로그인·정부사이트라 브라우저 자동화(매크로)는 비권장 →
  국세청이 제공하는 **엑셀 일괄 업로드 양식**을 생성해주는 방식을 유지합니다.
