# 부릉 사업소득 수정신고 — 자동화 도구

`수정신고_부릉` 시트의 데이터를 **ERP(옴니이솔) 업로드 엑셀**로 자동 변환해서,
구글시트 ↔ ERP 창 전환과 수기 입력을 줄여주는 Google Apps Script입니다.

> 목표: 매뉴얼 「01. ERP 사업소득 데이터 수정 → 방법2 엑셀업로드」 단계를 버튼 한 번으로.
> (홈택스 간이지급명세서 생성기는 국세청 업로드 양식 확보 후 추가 예정)

---

## 1. 설치 (최초 1회, 5분)

1. `수정신고_부릉` 이 들어 있는 구글 스프레드시트를 연다
2. 상단 **[확장 프로그램] → [Apps Script]**
3. 기존 코드 지우고 **`ERP_업로드_생성기.gs`** 내용을 통째로 붙여넣기 → 저장(💾)
4. 스프레드시트로 돌아가 **새로고침(F5)** → 상단 메뉴에 **[부릉 자동화]** 가 생김
5. 처음 실행 시 구글 권한 승인 창이 뜨면 본인 계정으로 허용

---

## 2. 사용법

### ① ERP 업로드파일 생성 (소득해당자)

1. (권장) 이번에 처리할 **행들을 드래그로 선택** — 선택한 행만 생성됨
   *아무것도 선택 안 하면 시트 전체가 대상이 되어 과거 완료분까지 다시 나옵니다.*
2. **[부릉 자동화] → [① ERP 업로드파일 생성(소득해당자)]**
3. 새 스프레드시트가 만들어지고 링크가 뜸 → 그 파일을 열어
   **[파일] → [다운로드] → [Microsoft Excel(.xlsx)]**
4. 옴니이솔 **[사업기타이자배당소득엑셀업로드] → [엑셀파일업로드]**
   → 전체 선택 → **[오류검증]** → '정상' 확인 → **[서식반영]**

생성물은 실제 ERP 양식(`TSMINC00700_F`)과 컬럼·시트명이 동일하며,
**모든 셀이 텍스트 서식**으로 채워집니다(매뉴얼의 "숫자(X) 텍스트(O)" 준수).

### ② 부인자 삭제 대상 목록

부인자의 기존 소득을 ERP에서 **승인해제+삭제**하는 작업은 엑셀업로드로 안 되므로 수동입니다.
이 메뉴는 그때 참고할 **[부인자명 / 주민번호 / 귀속연월 / 금액]** 목록을 뽑아줘서,
시트를 왔다갔다 하지 않고 한 화면에서 삭제 작업을 할 수 있게 해줍니다.

---

## 3. 컬럼 매핑 (기본값)

| ERP 양식 | 값 출처 |
|---|---|
| `INCMPER_NO` 소득자코드 | (아래 4번 참고 — 소득자코드 매핑) |
| `PAY_YM` 지급연월 | `지급연월`(L) → `YYYYMM` |
| `RVERS_YM` 귀속년월 | `지급연월`(L) → `YYYYMM` (귀속=지급 동일 처리) |
| `PAY_DT` 지급일 | 해당월 **말일** `YYYYMMDD` |
| `BIZAREA_CD` 사업장코드 | `1000` (고정) |
| `DEPT_CD` 부서코드 | `AE0000000` (고정) |
| `WGS_AMT` 지급액 | `최종 소득금액`(AA). 비어 있으면 `해당자 기존(X) + 부인(M)` 자동계산 |
| `BIZTP_FG_CD` 업종구분코드 | `940918` 퀵서비스 (고정) |
| `TAX_RT` 세율 | `3` (고정) |
| `INTAX_AMT` 소득세금액 | `최종 소득세`(AB) *(폴백 시 Y+P)* |
| `LOCINTAX_AMT` 지방소득세금액 | `최종 지방소득세`(AC) *(폴백 시 Z+Q)* |

- **소득세 정합성 참고:** 최종 소득세 = 기존 + 부인(각각 따로 반올림된 값의 합)이라
  `지급액 × 3%` 와 몇 원 다를 수 있습니다. 이는 정상이며, 기존 신고분을 보존하는 올바른 값입니다.

---

## 4. ⚠️ 소득자코드(INCMPER_NO) 입력이 핵심

ERP 업로드 양식에는 **이름·주민번호 칸이 없습니다.** 소득자를 식별하는 값은
`INCMPER_NO`(소득자코드) 하나뿐이라, 이 값이 있어야 정상 반영됩니다.

`수정신고_부릉` 시트엔 소득자코드가 없으므로, 두 방법 중 하나로 채워주세요.

**방법 A — 매핑 시트 (권장)**
1. 같은 파일에 **`소득자코드매핑`** 이라는 시트를 만든다
2. `A열 = 주민번호`, `B열 = 소득자코드` 로 채운다 (1행은 제목행)
   *(옴니이솔 `소득자등록`에서 소득자 목록을 내려받아 붙여넣으면 편함)*
3. 생성기가 해당자 주민번호를 보고 소득자코드를 자동으로 채워줍니다

**방법 B — 시트에 열 추가**
- `수정신고_부릉`에 소득자코드 열을 만들고, `CONFIG.COL.해당자_소득자코드` 에 그 열번호를 적는다

> 매핑을 못 찾은 대상은 생성 후 경고창에 명단으로 뜨고, 해당 셀은 비어서 나옵니다.
> 신규 소득자라 코드 자체가 없으면 매뉴얼 FAQ(신규 등록)로 먼저 코드를 부여하세요.

---

## 5. 값이 실제와 다르면?

`.gs` 파일 맨 위 **`CONFIG`** 블록만 고치면 됩니다. 예:

- 지급액 기준을 '이관금액만 추가'로 바꾸려면 → `AMOUNT_BASIS: 'DENIED'`
- 부서코드/세율/업종코드 변경 → 해당 값 수정
- 시트 열 순서가 바뀌면 → `CONFIG.COL` 의 열번호만 수정

## 6. 아직 수동인 부분 / 다음 단계

- **부인자 삭제**(승인해제+삭제): ERP 엑셀업로드로 불가 → 수동 유지 (②번으로 보조)
- **홈택스 간이지급명세서/지급명세서 수정신고**: 국세청 업로드 양식 확보 후 생성기 추가 예정
- 홈택스는 공동인증서 로그인·정부사이트라 브라우저 자동화(매크로)는 비권장 →
  국세청이 제공하는 **엑셀 일괄 업로드 양식**을 생성해주는 방식으로 붙일 계획
