## 2. 추진 목적

**핵심 메시지: 반복 업무를 줄이고, 사람이 바뀌어도 유지되는 구조를 만든다**

2. **누락과 실수 제거**

3. **속인화 해소**

## 3. 기존 프로세스 (8월 안내 기준)

**핵심 메시지: 7월 말에 대상자를 확정하고 발송하는 4단계 수작업**

- **STEP 0 (연 1회 · 4월)**
  - ERP 이관 완료 후, 4/30 기준 재직자 생일 확인
  - 옴니이솔 > 근태일수등록 > 사원별일수등록에서 생일휴가 1일 일괄 부여
  - 시작일 = 생일월 1일 / 종료일 = 생일월 말일
- **STEP 1 (매월 말)**
  - 사원명부 재조회 → 신규 입사자 중 익월 생일자에게 추가 부여
  - 퇴직 · 휴직자 부여 내역 삭제 후 안내 대상 제외
  - 임원 부여 내역 삭제 후 안내 대상 제외
- **STEP 2 (검토)**
  - 추려진 대상자 목록을 사수님께 전달해 컨펌
- **STEP 3 (발송)**
  - 슬랙에서 템플릿의 "월"과 "이름"을 직접 수정해 1명씩 수동 발송

- **문제점**
  - 단순 반복 작업 누적 → **템플릿 이름 미수정 발송 사례 발생** (수신 확인 전 수정)
  - 매월 동일 작업 반복에 따른 시간 소요
  - 절차가 문서화되지 않아 인수인계 시 재현 곤란

## 4. 접근 방식의 전환

**핵심 메시지: 처음 시도한 방식이 막히면서 판단 기준을 바꿈**

- **1차 시도 — 슬랙 자동화**
  - ERP 사원명부만 넣으면 대상자 선별 후 슬랙 DM 발송하는 도구 구상
  - 인턴에게 슬랙 API 권한 미부여로 무산
  - 권한 확보하더라도 **인턴 교체 시마다 재부여 필요** → 지속가능성 부족

- **전환 — 구글 스프레드시트 + Gmail**
  - 관리자 승인 없이 본인 구글 계정 권한만으로 동작
  - 담당자 변경 시 동일 절차로 인수 가능
  - 추가 비용 · 외부 서비스 계약 없음

- **판단 기준: "권한 없이 동작하는가" + "다음 담당자가 이어받을 수 있는가"**

## 5. 개선 방식

**핵심 메시지: 스프레드시트 메뉴 4단계로 완료**

- **⓪ 명단 대조**
  - ERP 최신본과 자동 비교
  - 휴직 · 퇴직 반영, 신규 입사자 자동 추가
- **① 대상 분류**
  - 생일월 자동 계산
  - 임원 · 휴직 · 제외 부서 · 테스트 계정 자동 판별
- **② 테스트 발송**
  - 본인 메일로 견본 발송, 문구 · 서명 사전 확인
- **③ 일괄 발송**
  - 개인화된 안내 메일 발송, 결과 자동 기록

- 하단 강조: 별도 서버 · API 계약 · 관리자 승인 없이 구글 계정 권한만으로 동작

## 6. 주요 기능

**핵심 메시지: 규칙은 자동으로, 최종 판단은 사람이**

1. **명단 자동 최신화**
   - 재직여부 · 직급 · 직책 · 비용센터 · 이메일 5개 항목 변경 감지
   - 변경 내역은 [대조결과] 시트에 기록, 명단 최종 수정일 자동 갱신
   - ERP 양식의 열 순서가 달라도 항목명으로 자동 인식
2. **자동 대상 선별**
   - 생년월일에서 생일월 계산
   - 재직 상태 · 직급 · 부서 규칙에 따라 대상/비대상 분류
3. **개인화 메일 발송**
   - 수신자 이름 · 사용 기한 자동 치환
   - 발신자의 회사 Gmail 서명 자동 첨부
4. **중복 발송 차단**
   - 사원번호 + 연월 기준 발송 이력 관리
5. **사람의 최종 확인**
   - 자동 분류 결과를 체크박스로 제시, 발송 전 담당자 확인 · 수정

- 안전장치: 테스트 발송 사전 확인 · 발송 전 인원수 재확인 · 실패 건 사유 기록

1. **회사 로고 서명 적용**
   - Gmail 서명 연동 완료로 브랜드 서명 자동 첨부

   - 업로드 양식이 정형화되어 있어 동일 시트에서 생성 가능

### 요청사항
1. **운영 계정 이관 결정**
   - 현재 담당자 개인 계정으로 발송 → 인턴 종료 시 중단
   - 팀 공용 계정 또는 사수 계정 이관 필요
2. **사원명부 이메일 열 노출 검토**
   - 현재 export에는 포함되나 조회 화면에서는 숨김 상태
3. **임원 판별 기준 확정**
   - 현재 직급 · 직책 목록 기반 판별
   - 인사 규정상 '임원' 정의와 일치 여부 확인 필요
